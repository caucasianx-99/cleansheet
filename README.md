# CleanSheet

CleanSheet is a browser-based CSV cleaning and analysis tool built with HTML, CSS, and JavaScript.

It is an independent portfolio project designed to demonstrate practical data-processing, JavaScript, interface development, testing, and AI-assisted development workflows.

## Live Demo

https://caucasianx-99.github.io/cleansheet/

## Features

- Upload CSV files
- Drag-and-drop CSV import
- Automatic dataset summary
- Row and column counting
- Duplicate detection
- Missing-value detection
- Remove duplicate rows
- Remove completely blank rows
- Trim unnecessary whitespace
- Fill missing values in a selected column
- Remove rows with missing values
- Search and filter dataset contents
- Sort columns
- Paginated data preview
- Per-column statistics
- Automatic text/numeric type detection
- Numeric minimum, maximum, average, and median
- Reset data to the original imported state
- Export cleaned data as CSV
- Responsive browser interface

## Sample Dataset

A deliberately imperfect sample dataset is included:

`dirty-customers.csv`

It contains duplicate records, missing values, blank rows, and unnecessary whitespace so the cleaning features can be tested.

## How to Use

1. Open the live demo.
2. Upload a CSV file using the file picker or drag and drop.
3. Review the dataset summary.
4. Apply the required cleaning operations.
5. Search, sort, or inspect individual columns.
6. Review column statistics.
7. Download the cleaned CSV.

All CSV processing is performed directly in the browser.

## Development Approach

This project was built through an AI-assisted development workflow.

Generative AI was used for coding assistance, implementation guidance, debugging, and development planning. The project files were manually created and maintained in Visual Studio Code, functionality was tested in the browser, sample data was used to verify results, and the final application was manually reviewed before publication.
